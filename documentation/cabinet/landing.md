# Лендинг проекта

Публичная страница магазина: описание сервиса, тарифы с ценами, три шага
подключения и частые вопросы. Появилась в 4.13.0. До неё посетитель сразу
попадал на форму входа.

## Адреса

| Адрес | Когда работает |
|-------|----------------|
| `https://ваш-домен/landing` | если reverse-proxy пропускает этот путь на бота |
| `https://ваш-домен/cabinet/landing` | всегда, никаких правок прокси не нужно |

Обе ссылки открывают одну и ту же страницу. Первая короче и лучше смотрится в
рекламных постах.

## Нужно ли править nginx

Зависит от вашего конфига:

- **Проксируете на бота всё** (`location / { proxy_pass … }`) — ничего делать не
  надо, `/landing` уже работает.
- **Посторонние пути редиректите на `/cabinet/`** (как в шаблоне установщика до
  4.13.0) — короткий адрес уйдёт в редирект. Добавьте для него свой `location`:

```nginx
location /landing {
    proxy_pass http://127.0.0.1:<HEALTH_CHECK_PORT>;
    proxy_http_version 1.1;
    proxy_set_header Host              $host;
    proxy_set_header X-Real-IP         $remote_addr;
    proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

Шаблон в `scripts/meows-shop-setup.sh` это уже учитывает — если конфиг
генерируется установщиком, достаточно перегенерировать его.

Проверка:

```bash
curl -sI https://ваш-домен/landing | head -1   # ждём 200, а не 302
```

## Что настраивать

Отдельного наполнения у страницы нет — всё берётся из уже заданных настроек:

| На странице | Откуда |
|-------------|--------|
| Название и логотип | `CABINET_BRAND_NAME`, `CABINET_BRAND_LOGO_URL` / `CABINET_BRAND_LOGO_FILE` |
| Кнопка бота, поддержка, канал, документы | `BOT_URL`, `SUPPORT_URL`, `CHANNEL_URL`, `PUBLIC_OFFER_URL`, `PRIVACY_POLICY_URL`, `TERMS_OF_SERVICE_URL` |
| Тарифы и цены | ваша витрина тарифов; работают оба режима `SALES_MODE` |

Чего нет в настройках — то на странице не появится: пункт просто не отображается.
Поменяли тариф в админке — лендинг обновится сам, кэшировать нечего.

## Тексты

Правятся в переводах кабинета — ключи `landing.*` в файле `ru.json` (и `en.json`
для английской версии). В образе они лежат в `/translations/cabinet/i18n`, так
что каталог можно вынести в volume и менять без пересборки.

Стоит проверить перед публикацией: в разделе «Возможности» и в блоке под hero
есть маркетинговые утверждения по умолчанию (пропускная способность, аптайм,
условия возврата) — приведите их в соответствие с вашим сервисом.

## Оформление в стиле лендинга внутри кабинета

Тот же визуальный язык доступен как декор-тема кабинета: **Настройки бота →
Оформление кабинета → тема «Туманность»** (`nebula`). Включается без
перезапуска, по умолчанию выключена. Список всех тем — в [../env.md](../env.md),
ключ `CABINET_DECOR_THEME`.
