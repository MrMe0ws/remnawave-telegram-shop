# Режимы продаж: classic и tariffs

Управляется переменной `SALES_MODE` в `.env`.

| Режим | Смысл |
|-------|--------|
| `classic` | Один набор цен из env (`PRICE_*`, `STARS_PRICE_*`). Простая покупка периода. |
| `tariffs` | Каталог тарифов в PostgreSQL: свои цены, трафик, устройства, squads. Покупка по шагам: тариф → период → оплата. |

Рекомендуется для новых установок: **`tariffs`**.

## Какие переменные на что влияют

| Переменные | `classic` | `tariffs` |
| ---------- | --------- | --------- |
| `PRICE_1` … `PRICE_12` | Основная цена подписки по периоду | **Обязательны при старте** (валидация конфига); используются для сида `standard` и как запасной ориентир; **фактическая цена покупки** — из `tariff_price.amount_rub` |
| `STARS_PRICE_*` | Цена в Stars по периоду (если Stars включены) | Для сида `standard` и при создании тарифа в админке; **оплата Stars** — из `amount_stars` в БД, либо расчёт через `RUB_PER_STAR`, если Stars в строке цены не заданы |
| `RUB_PER_STAR` | Может не использоваться | Опционально: расчёт Stars при оплате, если в `tariff_price` нет `amount_stars`; также подсказки при вводе цен в админке |
| `TRAFFIC_LIMIT`, `TRAFFIC_LIMIT_RESET_STRATEGY` | Лимит трафика при выдаче подписки | Лимит и стратегия **на уровне каждого тарифа** в БД; при сиде `standard` подставляются из этих env |
| `PAID_HWID_LIMIT`, `HWID_FALLBACK_DEVICE_LIMIT` | Лимит устройств при выдаче | Лимит **на уровне тарифа** в БД; сид `standard` берёт устройства из этих настроек |
| `HWID_ADD_PRICE`, `HWID_ADD_STARS_PRICE` | Доплата за доп. устройства | То же: доплата к счёту при выборе extra HWID |
| Промокоды (pending % скидка) | Вставка строки перед блоком способов оплаты в текстах `pricing_info_*` | Вставка перед строкой «Способы оплаты» на шаге выбора провайдера, если в тексте есть тот же HTML-маркер |
| Tribute | Без скидки по промокоду (как в коде) | Без изменений |

**Важно:** даже в режиме `tariffs` при старте **нужны** заданные `PRICE_1`…`PRICE_12` — это требование инициализации конфига, а не «вторая витрина» для покупателя.

## Тексты сценария покупки (tariffs)

Настраиваются в `translations/ru.json` и `translations/en.json` (ключи вида `buy_tariff_*`, `tariff_selected_*`, `tariff_payment_methods_text`, `payment_tariff_*`).

См. также [customization.md](./customization.md).

## Админка тарифов

При `SALES_MODE=tariffs` и настроенном `ADMIN_TELEGRAM_ID`:

- в Telegram-боте — раздел тарифов;
- в web-кабинете (`CABINET_ENABLED=true`) — `/cabinet/admin/*` (тарифы, цены, описание).

Подробнее по API и UI: `.cursor/docs/api/cabinet-rest.md`, `.cursor/docs/reference/admin-cabinet.md`.
