# Флаги стран

SVG 3×2, имя файла — ISO 3166-1 alpha-2 в нижнем регистре (`de.svg`, `se.svg`).
Взяты из npm-пакета `country-flag-icons` (каталог `3x2`) и положены сюда, а не
подключены зависимостью: набор статический, а лишний пакет в сборке ради
копирования файлов не нужен.

Отдаются со своего домена намеренно. Эмодзи-флаги не подошли — в системном
шрифте Windows нет глифов флагов, и вместо флага рисуются две буквы. Внешний
CDN не подошёл, потому что админку ставят в закрытый контур.

Рендерит их `features/admin/components/CountryFlag.tsx`.

Новая страна: положить сюда `<код>.svg` тем же размером 3×2. Пока файла нет,
компонент прячет картинку — интерфейс не ломается.
